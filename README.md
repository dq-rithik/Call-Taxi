# 🚕 Call Taxi Application – Java Console App

A menu-driven Call Taxi Booking System built using Core Java.
This application simulates real-world taxi booking by allocating the nearest available taxi, calculating fares, and tracking taxi availability based on time.

---

# 📌 Features

- 🚖 Book a taxi using pickup & drop points

- 📍 Nearest available taxi allocation

- 💰 Automatic fare calculation

- ⏱ Taxi availability handled using pickup & drop time

- 📋 Display all taxi details

- 🔍 Display single taxi details by Taxi ID

- ♻ Continuous menu-driven execution

# 🛠 Technologies Used

- Java (Core Java)

- Object-Oriented Programming (OOP)

- Java Collections Framework

- Console Input / Output (Scanner)
